# Solis

A free, open-source 3D game engine for stylized games, strategy games, online co-op and PvP, and big open worlds. Lightweight, beginner-friendly, and written in [Lust](https://github.com/Rhyslos/Lust).

Part of the Rhylib family, alongside Aventail 3D and Halberd.
