# crates/ui/src

| File | What it does | Main items |
| --- | --- | --- |
| `lib.rs` | Lists the modules and what the crate offers. | |
| `screen.rs` | What a screen is made of: elements (with a glow and an outline), anchors, fills, the scale rule, the player's UI size, and the screen's look (decision 0089). | `Screen`, `ScreenLook`, `Element`, `ElementKind`, `Anchor`, `Edge`, `Fill`, `Colour`, `ScaleRule` |
| `layout.rs` | A screen laid out on a real screen into shapes, at the player's UI size, with the screen's glow, outline and pixel size. Tests in `layout_tests.rs`. | `layout`, `layout_with`, `layout_at`, `boxes`, `scale_of`, `screen_scale`, `Shape` |
| `text.rs` | Fonts, paragraphs laid out and kept by text, style and fit, placed on the screen and aligned per line, and the letters' distance images in one atlas (decisions 0084 and 0129). Tests in `text_tests.rs`. | `Fonts`, `Atlas`, `Placed`, `SDF_SIZE`, `SPREAD`, `MAX_PARAGRAPHS` |
| `paragraph.rs` | A text laid out (decision 0129): a font per letter from the style's list, runs shaped, lines broken by Unicode's rules (`unicode-linebreak`), long words broken between letters, "…" when cut. Tests (line breaking, alignment, "…", fallback, project fonts, damaged fonts, keeping, the 2,000-line scale case) in `paragraph_tests.rs`. | `TextStyle`, `Fit`, `Paragraph`, `Line` |
| `shaping.rs` | Runs of text in one font shaped with `harfrust` (kerning, joined letters, accents), each kept by its words; a font the shaper can't take is never shaped again. The only place `harfrust` is used. | `Shaping`, `Shaped` (within the crate) |
| `captions.rs` | The ready-made caption screen (stage 1, translations; decision 0131): lines shown for a time or until stopped, by kind (a sound's caption, a voice's subtitle) as the player chose, the newest three as a view low in the middle on boxes as dark and as big as asked. Tests in `captions_tests.rs`. | `Captions`, `Look`, `Kind`, `LineId` |
| `markup.rs` | Text effects written inside a text (decision 0130): the words in square brackets read into plain words, effects' runs, icons, pauses and speeds, and mistakes where they are; written back. Tests and a fuzz test in `markup_tests.rs`. | `parse`, `write`, `Marked`, `Effect`, `Run`, `Icon`, `Beat`, `Mistake`, `ICON` |
| `effects.rs` | What a text's effects do to each laid-out letter: a wave, a shake, a colour, bold and slant, at a moment (decision 0130). Tests, with the layout's (waves never move it, icons in line, typing hides letters) and the 2,000-letter scale case, in `effects_tests.rs`. | `TextEffects`, `WAVE_HEIGHT`, `SHAKE_REACH`, `SLANT`, `FAUX_BOLD` |
| `typing.rs` | A text typing itself out (decision 0130): when each character shows from the screen's speed and the text's pauses and speeds, the same at any frame rate; the moments a typing sound plays on; when each text of a screen began. Tests in `typing_tests.rs`. | `TypeOut`, `Moment`, `SoundEvery`, `Started` |
| `font_files.rs` | A project's own fonts, checked as they're added, and a font ready to lay text out with (read and shaping). | `FontFiles`, `Slot` (within the crate) |
| `font.rs` | One font file read with `skrifa` (decision 0107): letters, advances and the line's height at a size, and a letter's outline drawn into how much of each pixel it covers. The only place `skrifa` is used. | `Font`, `Sized`, `Outline` (all within the crate) |
| `view.rs` | A screen written in Lust (decision 0087): the tree Lust's view gives, laid out with Lust's own rules (column, row, stack, space, text, button, image, progress, canvas with box, circle and line) into elements in design pixels; the player's text size (`Looks::text_percent`) grows text and the room round it, the screen's line height and letter spacing (`Looks`) reach every text, `font "a.ttf, b.otf"` names a text's fonts (the view's for every piece without one), a text is measured whole in its room (`Measure::text`) and asks for "…" by a limited `height`/`maxHeight` (or `width`/`maxWidth` when `nowrap`), and `shadow` is a glow. Tests in `view_tests.rs`. | `Node`, `Style`, `Measure`, `WithPictures`, `lay_out`, `boxes`, `design_of`, `colour` |
| `pictures.rs` | The pictures a game's screens show, packed into one atlas, each with its edge copied round it, colours premultiplied (decision 0089); cutting a crop out of a picture. Tests in the file. | `Pictures`, `Placed`, `split`, `cut`, `SIDE` |
| `source.rs` | A screen's Lust file as the UI editor reads and changes it (decision 0089): each view's pieces with where they are in the text, and edits that change the fewest letters (a `[ ]` item set or taken away, words or a value's code, a piece taken out, put in or moved), keeping comments and code as written. Tests and a fuzz test in `source_tests.rs`. | `parse`, `ScreenSource`, `Block`, `Piece`, `ElementSource`, `set_style`, `remove_styles`, `set_words`, `set_arg`, `remove_piece`, `insert_piece`, `move_piece` |
| `presets.rs` | The screen sizes the UI editor previews. | `PRESETS`, `custom` |
| `sample.rs` | The mock-up's sample HUD. | `hud` |
