# editor/assets

Files built into the editor program itself.

| Folder | What it holds |
| --- | --- |
| `fonts/` | The editor's fonts, built in by `src/theme.rs`: `Inter-Regular.ttf` and `Inter-SemiBold.ttf` (interface text) and `JetBrainsMonoNL-Regular.ttf` (monospace text: the console, the frame rate). Their licences are in [`licenses/fonts`](../../../licenses/README.md). `fonts/` has no README of its own: it holds only the font files, shipped as they are. |

Anything added here needs its licence in `licenses/` (CONTRIBUTING.md, "Third-party material").
