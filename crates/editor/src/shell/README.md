# editor/src/shell

The frame round the editor, as the project lead's design has it ([decision 0099](../../../../docs/decisions/0099-the-g-layout.md); the design is `docs/design/g-layout/`, the plan `docs/plans/shared-1-ui-remake.md`), remade by the editor rethink ([decision 0118](../../../../docs/decisions/0118-the-editor-rethink.md), boards in `docs/design/ui-rethink/`): the tab bar, the ribbon, then **one frame on every tab** (a left slot and a right slot running full height, the centre of one or two editor groups between them, and the bottom panel under the centre only), then the status line; on the File tab and an unbuilt screen, one page in place of the ribbon and the frame. Docking is Solis's own and fixed ([decision 0104](../../../../docs/decisions/0104-docking-is-solis-s-own.md)): each tab fills the same slots from a table, and today's panels are drawn inside them (`PanelViewer::draw_panel`). The layout chosen in Preferences › Layout moves the slots on every tab; every edge drags, and each tab remembers its sizes per layout (or shares one set).

## Adding to it

- **A new thing the editor can do:** add it to `ShellCommand` (and to `ALL`), give it its words in `command_words.rs` and its `why_not` and `run` in `commands.rs`. It is in the search at once. Put it on a ribbon by adding a line to that tab's table.
- **A control the engine can't do yet:** list it in the table as `unbuilt_at(shape, Entry::Unbuilt(UnbuiltId::..))`. Never draw one by hand ([`../unbuilt/`](../unbuilt/README.md)).
- **A new key or mouse action** needs the project lead's answer first (rule 17 of CONTRIBUTING.md).
