# editor/src/shell

The frame round the editor, as the project lead's design has it ([decision 0099](../../../../docs/decisions/0099-the-g-layout.md); the design is `docs/design/g-layout/`, the plan `docs/plans/shared-1-ui-remake.md`). Five bands, top to bottom: the tab bar, the ribbon, the editor groups, the shelf and the status bar; on the File tab and an unbuilt screen, one page in place of the ribbon, groups and shelf. Docking is Solis's own and fixed ([decision 0104](../../../../docs/decisions/0104-docking-is-solis-s-own.md)): each tab's middle is a table, and today's panels are drawn inside it (`PanelViewer::draw_panel`). On Home, the panel layout chosen in Preferences ([decision 0109](../../../../docs/decisions/0109-layouts-as-a-setting.md)) puts the Area, Properties and Assets lists in columns of their own beside the groups, or on the shelf as designed; every border between parts drags, and each tab remembers its sizes per layout.

## Adding to it

- **A new thing the editor can do:** add it to `ShellCommand` (and to `ALL`), give it its words in `command_words.rs` and its `why_not` and `run` in `commands.rs`. It is in the search at once. Put it on a ribbon by adding a line to that tab's table.
- **A control the engine can't do yet:** list it in the table as `unbuilt_at(shape, Entry::Unbuilt(UnbuiltId::..))`. Never draw one by hand ([`../unbuilt/`](../unbuilt/README.md)).
- **A new key or mouse action** needs the project lead's answer first (rule 17 of CONTRIBUTING.md).
