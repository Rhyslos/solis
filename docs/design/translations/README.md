# docs/design/translations

The mock-up of translations and subtitles (the game stages, stage 1; [decision 0131](../../decisions/0131-translations-and-captions.md)). The project lead approved the quick sketch (`00-quick-sketch.png`) on their phone on 2026-11-18, before the overnight run, and asked for the rest to be drawn and built, reviewing it after. The drawings are HTML laid over a real screenshot of the editor (1440 × 900, the sample harbour level on Home), in the G layout's colours, fonts and sizes.

| File | Shows |
| --- | --- |
| `00-quick-sketch.png` | The approved quick sketch: the languages (English as main, Norsk at 96%, Deutsch at 41%), + Language and Export spreadsheet; the translations side by side with a missing line marked; the player's subtitle and caption settings |
| `01-project-settings-languages.png` | Project settings › **Languages**: a row per language with its code, how much is translated (a bar and the count missing), the main one's chip and each row's ⋯ (Make main, Show in Translations, Remove); + Language ▾ open with the languages Solis knows and a code typed; Open the Translations tab, Export spreadsheet and Import; the In game code card; and the player's Subtitles and captions card (Subtitles, Captions for sounds, Size, Background, Language), used while playing in the editor |
| `02-the-translations-tab.png` | The **Translations** tab beside the level's view: the language shown beside the main one, the count missing, the search, Missing only, + Key, Export spreadsheet and Import; the grid of keys, the main language and the other, a missing line marked in red, the cell typed in outlined in the accent; and the note saying where typing writes |
| `03-a-caption.png` | The ready-made caption screen over a game: a sound's caption and a voice line's subtitle with its speaker in gold, each on a box as dark and as big as the player chose |

**Differences from the quick sketch:** the player's settings are a card on the Languages page (they're the player's, used while playing in the editor; a game offers them in its own menu), and gain the player's Language; the Translations tab's bar gains Missing only, + Key and Import; each language row shows its code, and the main language its count of lines.
