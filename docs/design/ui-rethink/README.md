# docs/design/ui-rethink

The approved mock-ups of the editor rethink (Shared 1f; [the plan](../../plans/editor-rethink.md), [decision 0118](../../decisions/0118-the-editor-rethink.md)). The project lead approved them on 2026-11-17, with two additions that weren't drawn:
- a prefab gets its own page, in its own tab;
- the left side toggles between the Level panel and the folder tree, and several folder trees can be open side by side to move files.

Where these mock-ups differ from the G layout (`../g-layout/`), these win.

| File | Shows |
| --- | --- |
| `01-launcher.png` | The launcher as its own window: projects as cards, search, a 2D and 3D filter, Learn and Updates |
| `02-new-project.png` | New project: the name makes the folder; Create in, remembered; Kind 2D, 3D or Both; templates |
| `03-home.png` | Home made clear: the Level panel, the view with the floating tool bar, Properties, and the Library under the view |
| `04-library.png` | The Library browser: the project's own folders, double-click to rename, the right-click menu |
| `05-bottom-panel.png` | The bottom panel collapsed to one thin line and open, beside today's bottom bar |
| `06-layouts.png` | Preferences › Layout as drawn miniatures, applied at once |
| `07-prefabs.png` | Prefabs: Make prefab, its card, linked copies, Open and Unlink |
| `08-2d-project.png` | A 2D project with every 3D-only part hidden |
| `09-every-tab.png` | One frame for every tab: left, centre, right, bottom; every edge draggable |
