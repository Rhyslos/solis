# docs/plans

Working plans for the phases of [ROADMAP.md](../../ROADMAP.md). A plan records the choices made before any code, the controls the project lead chose, and a plan for each milestone, so a later session can carry on where the last one stopped. Milestones are ticked off here as they are built. A plan marked "draft" still has questions for the project lead.
