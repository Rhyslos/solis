# The Console

> Messages from the editor, with the time each one arrived.

## When to use it
To see what the editor is doing and when something goes wrong. Today it reports the editor starting, the graphics card in use, and buttons whose features arrive in a later phase.

## How to use it
1. Each message shows its time, an icon for how serious it is, and the text. A long message is cut short; point at it to read it all.
2. The three buttons at the top show how many messages there are of each kind: information (ⓘ), warnings (⚠) and errors (✕). Click one to hide those messages, and again to show them.
3. Type in **Search** to show only messages containing that text (capitals don't matter).
4. **Clear** empties the Console.

The Console keeps the newest 2,000 messages.
